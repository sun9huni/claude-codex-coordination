# Agent Handoff Protocol

Chat sessions are not durable. Cursor, Claude, and Codex each lose state
when their conversation ends or their context fills. The repo must hold
the working state, not the chat.

Per-slice `.agent/status/<slice>.md` files are the authoritative working
state; this directory holds the derived index all three agents read. Legacy
snapshots may also exist under `state/`.

## Files

- `CURRENT.md` — the DERIVED lab-wide index (which session owns which
  slice), generated by `scripts/status.sh index`. Read first to orient;
  per-slice `.agent/status/<slice>.md` files are authoritative. Never hand-edit.
- `takeover-prompt.md` — paste into the new agent at session start.
- `handoff.md` — checklist to run before ending a session.
- `state/` — legacy/no-slice snapshots (`git status`, diff, log, notes).
- `archive/` — past slice status plus any matching legacy snapshots, dated.

## Flow

1. While working, update your slice's `.agent/status/<slice>.md` whenever a meaningful step lands.
2. Before ending the session: `./scripts/handoff.sh <next-agent> <slice>`, then `./scripts/status.sh index` to regenerate the `CURRENT.md` index.
3. New agent starts by reading the `CURRENT.md` index and the prompt in
   `takeover-prompt.md`.

## Shared with Codex and Claude

- `AGENTS.md` (root) — read by Codex and points to this protocol.
- `CLAUDE.md` (root) — read by Claude Code; mirrors `AGENTS.md`.
- `skills/handoff-writer/SKILL.md` — local Skill copy.
- `.codex/skills/handoff-writer/SKILL.md` — Codex-global Skill copy.

`scripts/skills-sync.sh` keeps the local and global skill copies aligned.
`scripts/remote-bootstrap.sh` ships these files to remote hosts.

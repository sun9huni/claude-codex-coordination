# .agent/handoffs/ — cross-session continuity

Chat sessions are not durable. This directory keeps the bridge.

| File | Role |
|---|---|
| `CURRENT.md` | Single source of truth for "what is happening now". Yaml frontmatter is machine-validated; Markdown body is human-readable. Update at end of every session. |
| `handoff.md` | The protocol: what fields are required, when to hand off, what's forbidden. |
| `takeover-prompt.md` | What an incoming agent does when continuing someone else's work. |
| `state/` | Auto-generated by `./scripts/handoff.sh`: `git-status.txt`, `git-log.txt`, `diff.patch`, `diff-staged.patch`, `session-note.md`, `meta.txt`. |
| `archive/` | Optional; move stale CURRENT.md + state here when starting a new chapter. |

## Lifecycle

```
Session start
  └─ Read CURRENT.md
  └─ (If owner_agent ≠ you) Open takeover-prompt.md, run steps 4-7
  └─ Optionally re-read state/diff.patch, state/git-status.txt to
     verify nothing has drifted since the prior session

Mid-session
  └─ Work happens in project repos
  └─ CURRENT.md is the running notebook (you can update it any time)

Session end
  └─ Update CURRENT.md (or call /handoff to be guided)
  └─ Run ./scripts/handoff.sh <next-agent>
  └─ Stop hook validates frontmatter on the way out
```
